# id consulting — сайт

Статический сайт. Точка входа — index.html.

## Файлы
- index.html — главная
- bankruptcy.html — практика «Банкротство»
- cases.html — кейсы
- insights.html — аналитика
- privacy.html — политика обработки персональных данных
- site.css — общие стили внутренних страниц
- geo-map.js — карта географии практики (главная)
- robots.txt, sitemap.xml — SEO

## Публикация
Любой статический хостинг (Timeweb, Beget, Netlify, Cloudflare Pages).
Корень сайта = корень репозитория, index.html — главная страница.

## Перед публикацией заменить
- домен в robots.txt и sitemap.xml
- телефон, email, реквизиты в index.html (в контактах, футере и JSON-LD)
- поля в квадратных скобках в privacy.html
